# Chat effects

Bots can mark a moment in a conversation they belong to: confetti for an everyday
win, fireworks for a major milestone, and pasta for something nobody is quite sure
about.

An effect plays once, the next time you have that conversation open, on whichever
of your devices shows it first; one you don't see within a day is dropped. With
Reduce Motion on, you see a still badge instead. An effect does not add a message
to the conversation.
